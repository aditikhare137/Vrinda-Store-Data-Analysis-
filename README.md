# Vrinda Store Data Analysis — Excel

An Excel-based data analysis project focused on exploring retail store data and presenting business-oriented insights from the workbook.

## Objective

Use spreadsheet analysis to examine store sales data, organise information, and identify patterns that can support business decisions. The exact findings should be taken from the analysis and visuals in the included workbook rather than assumed from the project title.

## Tool Used

- Microsoft Excel

## Project File

- `Vrinda Store Data Analysis.xlsx` — workbook containing the project data and analysis

## How to Explore

1. Download or clone the repository.
2. Open the Excel workbook in Microsoft Excel or a compatible spreadsheet application.
3. Review the source data, formulas, tables, and charts included in the workbook.
4. Trace each key insight back to the relevant data and calculation.

## Questions to Document from the Workbook

For a stronger portfolio presentation, add a short summary of the actual workbook findings, such as:
- Which products or categories contribute most to sales?
- How do sales vary by time period or customer segment?
- Which charts or calculations support the main recommendations?

Only include figures and conclusions that you have verified in the workbook.
